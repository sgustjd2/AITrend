## Decisions API 및 오픈 웨이트 의사결정 모델

[OpenAI 공식 변경 기록](https://developers.openai.com/api/docs/changelog)은 10월 22일 일반 제공을 마지막 Decisions 항목으로 싣고 있으며 2일 변경은 찾지 못했다. [공식 가이드](https://developers.openai.com/api/docs/guides/decisions)의 `POST /v1/decisions`는 텍스트·이미지 또는 둘을 입력으로 받아 `predicate`(참일 확률), `choice`(지정한 선택지), `score`(순서형 등급 분포의 평균)를 돌려주는 **호스팅 API**, 공개 가중치가 아니다. 문서 내에는 아직 공개 베타라는 문구가 남아 **변경 기록의 일반 제공 표시와 불일치**한다. 가이드 표기 단가는 `gpt-6-luna` 입력 100만 토큰당 미화 0.10달러, 출력 과금 없음; 지역·긴 문맥 할증은 별도. 2일 요금·지연 변경은 확인되지 않았다. API 제공자 자체의 속도 주장을 독립 평가로 취급하지 않는다.

**신규 공개 대안은 기존 d1-2B의 [LiteRT 변환본](https://huggingface.co/litert-community/d1-2B-LiteRT)**이다. 2일 07:29 UTC 생성, 08:22 UTC 변환 그래프·호스트·검증 데이터 업로드. 원본 [LiquidAI/d1-2B](https://huggingface.co/LiquidAI/d1-2B)는 1.92B 파라미터, BF16 Safetensors, LFM3-VL-2B 기반, 텍스트·이미지·영상의 `noul`(yes/no), `choice`, `score`뿐 아니라 값·위치 추출에도 특화했다. 변환본은 LiteRT float16 행렬·float32 연산, 단일 결정 그래프 약 **3.0GB 파일**, 최대 6,144 토큰의 변형 파일들과 영상 인코더 파일을 따로 제공한다. **원본 128K 문맥과 변환본 최대 6,144 토큰을 혼동하면 안 된다.** 라이선스는 LFM Open License v1.0으로 연 매출 미화 1천만 달러 이상 조직의 상업적 사용 제한을 카드가 고지한다. 코드·가중치·변환 스크립트·검증 요청 일부가 공개됐으나 원본 전체 학습 데이터는 카드로 확인할 수 없다. 표준 OpenAI Decisions API의 요청·응답과 직접 호환되지 않고 Liquid AI의 `system_one()`·`system_one_batch()`를 사용한다.

제작자는 M4 Max Metal의 지원 요청 단일 질문 중간값 **40.9ms**, 세 질문 **41.3ms**, 520건에서 원본 CPU 참조와 비동률 최상 선택 동일·확률 오차 3.68e-5 이하를 보고했다. 이는 **변환 일치성**이지 라벨 기준 정확도·보정된 확률의 독립 검증이 아니다. 원본 제작사 측 평가와 OpenAI 벤더 자체 주장 사이에는 공통 데이터셋/분할·임곗값·Brier/ECE·선택지 순서 실험이 없어 성능 숫자를 직접 비교할 수 없다. 일반 추론 채팅 LLM과 강화학습 Decision Transformer는 이 유형의 확률형 판정 모델 대체재로 세지 않는다. mini PC·GB10의 실제 필요 RAM과 처리량은 위 표대로 미확인이다.

조회 시점 [GitHub 일별](https://github.com/trending?since=daily)에는 에이전트 도구와 스킬이, [주별](https://github.com/trending?since=weekly)에는 Hallmark·Cloudflare 스킬 등이 노출되지만 **11월 2일 당시 등재·일별 별 증가량을 재구성할 자료는 없다**. 최근 30일 보고서의 같은 프로젝트는 이름만 바꿔 반복 소개하지 않는다. OpenQodex는 GitHub API 조회 당시 누적 별 **1,126**, 공개 생성일 **10월 2일**, 최신 릴리스 **10월 28일**이다. 따라서 위 국내 소개에 연결해 읽되 ‘2일 신규 버전’이나 ‘2일 급상승 별 수’라는 표현은 하지 않는다. 코드를 포함한 외부 리뷰 전송 여부는 설치 전에 개인정보·비밀값 경계로 확인할 사항이다.

## AI/Vision 업무 적용 판단과 한계

읽기 전용 PoC에서 **문서 OCR → 분리된 객체 탐지 → 판정 모델** 순으로 측정하는 것이 타당하다. Xiaomi 변환본은 허가된 한글 스캔과 표 병합 셀에서 정답률을 재며, YOLO26l MXQ는 전용 보드 부재 시 범용 배포 후보에서 제외한다. d1-2B LiteRT의 확률에는 업무별 오탐 비용에 맞는 임곗값·Brier/ECE·선택지 순서 교란 평가를 붙인다. 어떤 카드의 제작자 실험도 고객 현장 데이터의 독립 재현이 아니다. 외부 리뷰어를 쓰는 OpenQodex는 고객 정보·내부 코드의 외부 전송 가능성을 검토하고 승인 전에는 실행하지 않는다. 하드웨어 동작·보정 명령도 수행하지 않았다.
