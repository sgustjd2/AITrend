## Hugging Face 비전 모델과 실행 조건

### OvisOCR3: 브라우저용 문서 구조화 묶음 신규 등록

**사실.** [모델 카드](https://huggingface.co/multimodal-vision-ai/OvisOCR3-0.8B-WebGPU-ONNX)와 [대상일 이력](https://huggingface.co/multimodal-vision-ai/OvisOCR3-0.8B-WebGPU-ONNX/commits/main)은 원본 `ATH-MaaS/OvisOCR3`의 0.8B WebGPU용 **FP16 ONNX 외부 데이터** 내보내기, Apache-2.0 표시, 비전 인코더·토큰 임베딩·디코더 파일을 제시한다. 구조화된 문서 결과는 경계상자·범주·내용이 들어가는 JSON 배열이라는 카드 설명이다. 11월 7일 11:50 KST의 커밋 메시지는 `Publish validated OvisOCR3 0.8B WebGPU ONNX bundle`이다. 원본 OvisOCR3 자체가 이날 처음 발표됐다는 주장은 하지 않는다.

**판단.** 브라우저 문서 전처리의 실험 후보이지만 웹 브라우저의 WebGPU 지원, 외부 데이터 파일 전체 다운로드, 영상 인코더 메모리와 토큰 캐시를 별도 검증해야 한다. 카드의 `validated`라는 작성자 표현은 사용자의 장치에서 검증 완료를 뜻하지 않는다.

### OpenOCRv2: 검출·인식 분리형 신규 등록

**사실.** [카드·파일](https://huggingface.co/Yesianrohn/openocrv2/tree/main)과 [11월 7일 이력](https://huggingface.co/Yesianrohn/openocrv2/commits/main)에 따르면 `det/model.safetensors`, `rec_ctc/model.safetensors`, `rec_ar/model.safetensors`가 올라왔다. 카드 기재치는 검출기 9.36M·36MB, CTC 인식기 21.97M·85MB, AR 인식기 36.66M·141MB이고 라이선스 표기는 Apache-2.0이다. 대상일 22:28 KST 업로드 제목은 `Upload 12 files`다. 이 모델은 텍스트 영역 검출과 문자열 인식을 결합하는 OCR 구성이지 일반적인 이미지 질의응답 VLM이 아니다.

**판단.** 영수증·문서의 탐지 후 인식 파이프라인 검토에 적합하다. 영역을 잘못 잘라 인식기에 전달하면 결과가 무너질 수 있다. 자체 코드 파일을 로드할 때 `trust_remote_code=True` 예제가 있어 코드 실행 전 리뷰와 격리가 필요하다. 카드의 성능 주장은 독립 시험으로 확인하지 못했다.

## Decisions API와 오픈 웨이트 결정 모델

[OpenAI Decisions API 공식 가이드](https://developers.openai.com/api/docs/guides/decisions)의 `predicate`는 참일 확률, `choice`는 지정된 선택지, `score`는 순서 있는 단계의 가중 점수를 반환한다. 문서의 입력 범위는 텍스트·이미지·JSON이며 **호스팅 API**다. 오픈 가중치 배포나 강화학습의 Decision Transformer가 아니다. 문서에 적힌 속도·요금은 공급자 자체 설명으로 읽고, 대상일 변경 이력과 독립 지연 측정은 확보되지 않아 **11월 7일 API 업데이트라는 주장은 보류**한다. 문서의 현재 가격 문구가 시점별로 달라질 수 있어 이를 대상일 가격 변경으로 기록하지 않는다.

[Decido-1 26B-A4B 모델 카드](https://huggingface.co/decido-ai/decido-1-26b-a4b)는 Gemma-4-26B-A4B 기반의 LoRA 병합 모델, Apache-2.0 표시, yes/no·선택·순서형 척도와 확률 출력, GGUF CPU 및 bf16 GPU 경로를 기술한다. 카드의 26B 전체·토큰당 약 4B 활성, CPU 약 30GB RAM은 **작성자 표기**다. [Fast 카드](https://huggingface.co/decido-ai/decido-1-fast-1.7b)는 Qwen3-1.7B 기반이며 8GB RAM은 계열 표에 적힌 작성자 값이다. 두 모델 모두 11월 7일 21:11 KST의 **카드 수정**만 이번 신규 사실로 채택한다. 기존 가중치 공개일과 11월 8일 01:24 KST 후속 수정은 구분한다.

| 비교 기준 | Decisions API | Decido-1 / Fast |
|---|---|---|
| 결정 형식·입력 | 공식 `predicate`·`choice`·`score`; 텍스트·이미지·JSON | 카드상 yes/no·선택·등급. 문서 텍스트·JSON 경로, 이미지 동등 지원 미확인 |
| 공개 범위·호환 | 호스팅 서비스. 공개 가중치 없음 | Hub 가중치·카드, GGUF/bf16·도구 안내. 학습 데이터 전량 공개 여부 미확인; 카드가 주장하는 Jev 호환 경로는 OpenAI `/v1/decisions` 직접 호환의 근거가 아님 |
| 자원·적합성 | 로컬 메모리 비교 부적절 | Decido-1 CPU 약 30GB·Fast 약 8GB는 작성자 표기. 미니 PC 실사용 여유와 양자화 파일 종류를 별도 점검. GB10 최대 128GB는 실행 가능성의 충분조건 아님; 런타임·실측 미확인 |
| 성능 평가 | 문서의 약 10배 빠르다는 표현은 공급자 자체 비교 | 카드의 6개 그룹 평균·Jev 비교는 개발자 제시 수치. 동일 데이터셋·분할·평가 harness, Brier/ECE 확률 보정과 선택지 순서 편향의 **독립 동일조건 비교 없음** |

**업무상 판단.** 고객 문의 분류·문서 기반 위험 분류에 로컬 대안을 시험할 수는 있지만, 학습 데이터 범위·개인정보 처리·확률 보정과 순서 변경 재현성 검증 전 자동 의사결정에 투입하지 않는다. 오늘 카드에 추가된 `Decido-1-Max`는 계열 소개의 변경이며 신규 모델 가중치 배포로 판정하지 않는다.

NeurIPS·AAAI·ICRA·한국 전시회는 이 실행에서 공식 개최 일정과 현재 참가 등록 정보를 함께 확인할 수 있는 해당 기간의 행사를 확보하지 못해 추정 행을 만들지 않았다. 유료 등록이나 개인정보 입력은 수행하지 않았다.

## 적용 판단과 한계

먼저 문서 스캔 1개 유형에 대해 검출 누락률, 문서 구조 오류, 엔드투엔드 지연과 실제 메모리를 같은 장비에서 측정해야 한다. OvisOCR3는 브라우저 묶음이고 OpenOCRv2는 검출-인식 파이프라인이어서 카드의 파라미터나 파일 크기로 정확도를 직접 비교할 수 없다. 고객 문서 처리에는 권한·보존기간 및 오인식 후처리 검토가 앞선다. Decido 계열은 정확도만이 아니라 확률 보정, 보기 순서 교체 민감도, 금지 규칙 위반과 API 비교에서 입력 양식의 동일성을 따로 평가해야 한다. 이들은 **실무 제안**이지 대상일에 검증된 성능 결과가 아니다.
