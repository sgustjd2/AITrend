## Decisions API와 오픈 웨이트 의사결정 모델

[OpenAI Decisions API](https://developers.openai.com/api/docs/guides/decisions)는 `predicate`(참의 확률), `choice`(명시한 후보 중 선택), `score`(순서형 점수)의 **호스팅 API**다. 가중치 다운로드 모델이 아니다. 공식 가이드에는 공유 입력과 질문, 이미지·JSON 입력, 대화 이력, 프롬프트 캐싱, 요청당 최대 400문항 및 현행 지원 모델 `gpt-6-luna`가 기술돼 있다. 문서의 “What's new”는 베타 이후 변경을 묶어 설명하므로 **각 기능이 정확히 11월 5일 도입됐다는 근거는 없다**. [변경 기록](https://developers.openai.com/api/docs/changelog)에서 모델의 날짜별 출시와 가격·지연의 대상일 전후 비교를 확정하지 못해 변경 여부 미확인으로 둔다.

[Copernicus-31B의 카드](https://huggingface.co/Poindexter-Labs/Copernicus-31B)는 `choice`, `noul`(yes/no), `score`와 자체 `/v1/systemone` 서버를 기재한다. 최초 Hub 커밋은 11월 5일 05:13 KST, 같은 날 14:56 KST README 수정도 있다. 공개된 것은 모델 카드와 서버 코드·저장소 파일이며 학습 데이터 원본·훈련 재현 레시피의 공개 범위는 미확인. 카드 표기의 Apache-2.0과 약 31B는 저장소 주장으로 확인했지만 원본 기반 모델·학습 데이터의 라이선스 재검증은 필요하다. OpenAI API 요청·응답의 완전한 드롭인 호환, 확률 보정 및 실서비스 품질은 증명되지 않았다.

[기존 h2oai/h2o-lightning-4b](https://huggingface.co/h2oai/h2o-lightning-4b), [Qwen-9B-decision](https://huggingface.co/k4rth33k/Qwen-9B-decision), [hs-decide-1-flash](https://huggingface.co/hindsight-ai/hs-decide-1-flash)는 Hub 최근 커밋을 확인했으나 **대상일 신규 공개/변경이 확인되지 않아** 반복 뉴스에서 제외한다. 이것은 일반 대화형 추론 LLM 또는 강화학습 궤적을 예측하는 Decision Transformer의 성과 비교가 아니다. Copernicus 카드의 자체 성능 설명과 독립 평가를 분리해야 한다. 동일한 데이터셋·분할, 정확도, Brier/ECE, 선택지 순서 교란, 이미지 포함 여부를 맞춘 독립 대조가 없어 API와 오픈 웨이트의 수치 우열을 말할 수 없다.

**사실:** 당일 Ultralytics의 체크포인트 로딩 변경은 비전 학습 도구의 공급망 위험을 직접 다룬다. [커밋](https://github.com/ultralytics/ultralytics/commit/3b6b35d26374155140ed25e1b62483e5189569d9)을 반영하기 전 현재 배포판과 테스트를 대조한다. **추론:** MLX 변환본의 빠른 로컬 시험은 Apple Silicon에 적합할 수 있으나 OCR·영상·탐지 품질, 플랫폼별 실행 메모리, 모델 라이선스의 실사용 조건을 별도로 검증해야 한다. **불확실:** Copernicus의 결정 확률을 금전·의료·안전 판정에 바로 쓰기에는 보정/편향·독립 평가가 부족하다. 업무 내부 데이터는 승인 없이 외부 호스팅 API에 전송하지 않는다.
