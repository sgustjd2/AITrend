### Gemini API의 에이전트 도구 검색과 세계 생성

**사실(11월 19일):** [공식 변경 기록](https://ai.google.dev/gemini-api/docs/changelog#11-19-2026)에 따르면 `Tool retrieval`은 Interactions API 미리보기 기능이다. `defer_loading: true`로 지정한 함수의 스키마를 `tool_search`를 거쳐 불러오거나 `execution: "client"`로 자체 검색을 실행한다. 문서는 Gemini 3.6 이후 및 Gemini 4 계열을 언급한다. 같은 날짜에 `models/genie-4`가 Interactions API `v1beta`에서 일반 제공되며, 실시간 조향형 24fps 영상·동기화 48kHz 스테레오 오디오를 설명한다. 요금은 공식 문서에 유료 티어 및 토큰 단위로 제시된다. **판단:** B2B 에이전트에서는 도구 스키마 검색의 정확도·유출 통제·지연을 먼저 검증해야 하며 `Genie 4`는 3D 시뮬레이션/영상 생성이지 객체 탐지 모델이 아니다. 이 발표는 **Gemini Decisions API** 또는 공개 결정 가중치 출시의 근거가 아니다.

**사실(11월 19일):** [Glance-X-4B 카드](https://huggingface.co/Vision-Decision/Glance-X-4B)와 [저장소 이력](https://huggingface.co/Vision-Decision/Glance-X-4B/commits/main)은 공개 당일 기록을 보여 준다. ## Decisions API 및 Hugging Face 신규 의사결정 모델

[OpenAI API 변경 기록](https://developers.openai.com/api/docs/changelog)을 조사했지만 11월 19일의 결정 API 입력·요금·지연 변경은 확인되지 않았다. 특정 이미지·동영상 지원, 지연이나 가격 변동도 해당 날짜의 검증된 변경으로 제시할 수 없다. Google의 위 발표 역시 결정 유형 API 신규 공개로 분류하지 않는다.

## 업무 적용 판단과 한계

에이전트 운영자는 `Tool retrieval`을 소수 비민감 도구의 검색 재현율·호출 오류율·지연에서 먼저 시험하고 내부 스키마를 외부 서비스로 무단 전송하지 않아야 한다. 비전팀은 `Glance-X-4B`의 문구-객체 대응을 제조 현장 사진으로 평가하되 비상업 라이선스와 오탐을 먼저 처리해야 한다. 로컬 배포는 Q4 모델의 가중치 **계산 하한**이 실제 실행 메모리를 대표하지 않으므로 기종별 VRAM/통합메모리와 영상 입력 길이를 실측한다. 의사결정 라우팅은 학습 데이터 누출, 선택지 순서, 보정도와 사람 검토 경로가 확보되기 전에는 자동 승인에 넣지 않는다.
