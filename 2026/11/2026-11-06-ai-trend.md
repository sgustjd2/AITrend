## Decisions API와 오픈 웨이트 의사결정 모델

**구분.** [OpenAI Decisions 공식 문서](https://developers.openai.com/api/docs/guides/decisions)는 호스팅 API의 참조다. `predicate`의 참일 확률, 지정 선택지의 `choice`, 순서형 `score` 같은 구조화된 결과를 평가할 때 일반 대화형 추론이나 강화학습용 Decision Transformer와 구별해야 한다. 공식 가이드는 텍스트·이미지·JSON 입력을 설명한다. 가이드의 Responses API 대비 속도 표현은 제공사 주장이지 동일 조건의 독립 측정치가 아니다. 공개 문서·[변경 기록](https://developers.openai.com/api/docs/changelog)에서 **대상일 API 변경, 지원 입력·요금·지연의 변경 증거를 확인하지 못했다**. 따라서 가격 인상·성능 개선·API 신기능을 당일 뉴스로 쓰지 않는다. 아래 모델은 OpenAI의 가중치 공개가 아니다.

**신규 참조: [Decido-1 (26B-A4B)](https://huggingface.co/decido-ai/decido-1-26b-a4b).** Hub 생성 **2026-11-06 13:42 KST**, [업로드·모델 카드 커밋](https://huggingface.co/api/models/decido-ai/decido-1-26b-a4b/commits/main)도 대상일에 확인된다. [모델 카드](https://huggingface.co/decido-ai/decido-1-26b-a4b)는 Gemma-4-26B-A4B-it 기반 미세조정, 총 약 26B/활성 약 4B, Apache-2.0, bf16 safetensors 및 Q8_0 GGUF를 명시한다. 카드에 따르면 문서·JSON 입력에 대해 yes/no, 미리 정의한 2~255개 선택지, 2~10단계 등급의 확률을 반환하며 별도 패키지의 `/v1/systemone` 호환 엔드포인트를 제공한다. 이 호환성은 **모델 제작자의 설명**이고 OpenAI Decisions API와의 완전 호환 검증은 아니다. 가중치와 LoRA·예제·패키지 공개는 카드에 명시되지만 학습에 쓴 약 16.3만 질문의 원본 데이터 전체 재배포와 사용 권한은 별도 검증이 필요하다.

**측정과 실행 한계.** 카드에는 Q8_0 GGUF **25.6 GB**, bf16 가중치 **48 GB**, M4 Pro CPU 실행 메모리 **약 30 GB**라고 적혀 있다. 이는 제작자 조건이며 다른 mini PC의 16 GB 통합메모리 또는 외장 GPU VRAM만으로 실행된다는 증거가 아니다. 32 GB 이상 구성도 운영체제·문맥·KV 캐시·동시성 여유가 필요하다. GB10 구동 실측과 공식 요구량은 미확인이다. 제작자는 여섯 평가군 평균 점수 CPU **85.38**, 비교 대상 Jev 1.13의 발표값 **83.85**를 제시하지만 독립 재현이 없고 측정 환경·데이터 분할과 누출 가능성 확인도 부족해 우열 결론을 내리지 않는다. 카드의 Brier·10-bin ECE는 일부 집합별로 방향이 다르며 선택지 순서 변경 시 답이 바뀌는 비율도 제작자 측정이다. 실제 도입은 한국어 도메인 고정 평가셋으로 정확도·Brier/ECE·순서 변경·처리량을 별도 비교해야 한다. 단순 전체 평균, API 제공자 자체 수치, 다른 하드웨어 지연을 한 축에서 비교하지 않는다.
