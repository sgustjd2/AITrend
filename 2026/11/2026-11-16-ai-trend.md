## GitHub 에이전트 기술

[tradermonty/claude-trading-skills](https://github.com/tradermonty/claude-trading-skills)는 대상일 범위의 [커밋](https://github.com/tradermonty/claude-trading-skills/commit/427b1f7d060840fa1c336445e7b6d5f5f8eb5b7c)에서 여섯 skill 진단의 API 키 노출 방지를 제목으로 표시했다. 저장소의 커밋 날짜 범위는 GitHub API의 KST 대상일 구간으로 필터링했다. B2B 도입 전 실제 패치 차이와 비밀정보 마스킹 회귀 테스트가 필요하다. [google-labs-code/stitch-skills](https://github.com/google-labs-code/stitch-skills), [NVIDIA/SkillEvaluator](https://github.com/NVIDIA/SkillEvaluator), [ag-ui-protocol/ag-ui](https://github.com/ag-ui-protocol/ag-ui)의 저장소 현황도 조회했지만 대상일 새 릴리스·별 증가량은 검증하지 못했다. 조회 시 star 총량은 단기간 증가량이 아니다. 이전 30일 보고서와 완전 대조되지 않아 재소개를 보류한다.

| 행사 | 공식 일정·장소 | 참가 신청 상태·가격/마감 | 업무 관련성·공식 링크 |
