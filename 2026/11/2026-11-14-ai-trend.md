## Decisions API 변경 확인

[OpenAI Decisions 문서](https://developers.openai.com/api/docs/guides/decisions)에서 `predicate`는 조건의 확률, `choice`는 미리 정의된 선택지, `score`는 등급이다. 이미지·텍스트 입력 지원과 요금·지연시간의 **11월 14일 변경 공지**는 확인되지 않았다. 이는 원격 **호스팅 API**이지 가중치를 배포한 모델이 아니다. Google의 별도 Decisions API 당일 공식 변경도 확인되지 않아 발표로 적지 않는다. 일반 대화 LLM이나 강화학습의 Decision Transformer와는 다른 비교 대상이다.

## AI 행사·학회 캘린더

주최 측 [AAAI-27](https://aaai.org/conference/aaai/aaai-27/) 페이지는 2027년 2월 16~23일 Montréal 개최를 명시한다(이번 보고서의 당일 발표가 아닌 향후 일정). [공식 등록 페이지](https://aaai.org/conference/aaai/aaai-27/aaai-27-registration/)는 **참가 등록 중**이며 2026년 12월 15일 23:59 EST까지 AAAI 기존 회원 기술 프로그램 조기 요금 USD 750(회원 유형·부가 프로그램별 상이)을 명시한다. 논문 제출과 별도의 정식 참가 등록이다. [ICLR 2027](https://iclr.cc/Conferences/2027), [CVPR 2027](https://cvpr.thecvf.com/), [ICRA 2027](https://2027.ieee-icra.org/) 공식 페이지는 열었으나 날짜·도시·정식 참가 등록 상태를 함께 확인하지 못해 일정표에서 보류한다. 한국 행사도 공식 등록 상태 확인 전 기재하지 않는다. 논문 제출·전시 부스 신청을 참가 등록으로 간주하지 않으며, 어떤 신청·결제도 실행하지 않았다.

## AI/Vision 업무 적용 판단과 한계

- **분석:** 구조화 의사결정은 승인·권한 부여나 의료 판단을 자동화하기보다 추적 가능한 보조 분류기로 파일럿하는 편이 안전하다. 카드의 자체 성능 주장은 독립적인 분포 이동·한국어·보정·순서 민감도 시험을 대체하지 못한다.
- **분석:** OCR FP8은 반복 서류의 구조화 추출 실험 후보이나 입력 해상도·문서 언어·표 좌표·FP8 커널·실측 지연시간을 표준 테스트셋에서 먼저 확인해야 한다. 가중치 메모리 계산만으로 mini PC 장착 여부를 결정하지 않는다.
