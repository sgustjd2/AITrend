### Android 화면의 다음 행동을 예측하는 VLM

**사실:** [공식 카드](https://huggingface.co/alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1)는 `LiquidAI/LFM3-VL-2B`를 LoRA 미세조정·병합한 `alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1`을 설명한다. Hub 생성 시각 `2026-11-21 12:02 UTC`(21:02 KST), 마지막 수정 `19:44 UTC`(다음 날 04:44 KST)로, **대상일 신규 생성**과 이후 평가 자료 업로드를 구분한다. 카드 기준 단일 스크린샷과 영어 목표·최근 행동을 입력해 클릭·스크롤·대기 등 JSON 한 행동을 반환한다. BF16 파라미터는 Hub 표시 1,918,181,888개. 카드의 `LFM Open License v1.0`(`license_name: lfm1.0`, Hub 분류 `other`) 조건을 확인해야 하며 일반 Apache 라이선스라고 쓰지 않는다. [GGUF 변형](https://huggingface.co/alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1-GGUF) 링크는 카드에 있다. v4 대비 `wait` 루프를 줄이려는 훈련 텍스트 수정이 핵심이지만 개선 성공은 입증되지 않았다.

**한계·적용:** 카드에 기재된 AndroidWorld `18/116` 등은 **이전 v4 참조 결과**로 v4.1 새 점수가 아니다. 모델 작성자도 평가 진행 중이며 실계정·메시지·결제에 무감독 사용하지 말라고 명시한다. 비전 업무에서는 화면 조작 실험용 격리 기기와 재현 가능한 작업 세트부터 검토한다. [카드 및 커밋](https://huggingface.co/alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1/commits/main).

**사실:** [PG-StreetParse-M 공식 카드](https://huggingface.co/pictograph/pg-streetparse-m)는 `Roboflow/rf-detr-seg-medium` 기반 A2D2 도로 이미지의 차·보행자 등 여섯 클래스 마스크 모델로, `432×432` 입력과 **FP32 ONNX**(`pg-streetparse-m.onnx`)를 명시한다. Hub 생성 `2026-11-21 03:29 UTC`(12:29 KST), `Publish PG-StreetParse-M from Pictograph` 커밋 확인. 파라미터 수는 공식 카드에서 미확인. 라이선스 `CC BY-ND 4.0`의 변경금지·표시 조건과 원 데이터 라이선스를 사용 전 검토해야 한다. 카드의 `mAP 18.9%`, `mAP@50 36.8%`는 **제작자 A2D2 자체 측정**으로, 독립 성능 또는 YOLO와의 공정 비교가 아니다. [커밋](https://huggingface.co/pictograph/pg-streetparse-m/commits/main).

**분류·판단:** 이 모델은 VLM이 아니라 RF-DETR 기반 분할기다. 주행 영상의 대상별 마스크를 검토할 수 있지만 야간·우천·자사 카메라 도메인으로 일반화한 근거는 없다. [Ultralytics 릴리스](https://github.com/ultralytics/ultralytics/releases/tag/v8.4.216)의 확인된 공개 시각은 **11월 20일 UTC**이므로 대상일 YOLO 신제품으로 싣지 않는다.

## Decisions API와 Hugging Face 신규 의사결정 모델

**배경(당일 신제품 아님):** [OpenAI Decisions 공식 가이드](https://developers.openai.com/api/docs/guides/decisions)는 `predicate`(참일 확률), `choice`(정해진 선택지), `score`(순서형 판단)를 다루는 **호스팅 API**이며 가중치 공개가 아니다. 지원 입력·실제 요금·지연의 **11월 21일 변경**은 확인되지 않았다. 이전에 게시된 [Google Gemini Decisions API 발표(2026-11-11)](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/) 역시 별도의 호스팅 서비스로, 대상일 발표로 재포장하지 않는다. 일반 추론 LLM과 상태·선택지를 조건으로 학습한 Decision Transformer를 동일 API의 대안으로 분류하지 않는다.

### Hugging Face 신규 의사결정 모델

**사전 점검 범위:** `decision-models-2026-11-21.json`의 Hub 검색 후보는 `new=13`, `updated=15`, `excluded=0`이다. 이 수는 **적합 판정 통과 수가 아니다**. 검색 이름만으로 포함시키지 않고 확인된 카드의 결정 출력·저장소 변경 성격을 분리했다.

**신규·[Turion Jev 4B 공식 카드](https://huggingface.co/turion-ai/turion-jev-4b):** 제작자 Turion AI, 저장소 생성 `2026-11-21 07:36 UTC`(16:36 KST), Qwen3.5-4B 기반 미세조정 **BF16 4,205,751,296 파라미터**, Apache-2.0. 입력은 **텍스트만**이며 `choice`, yes/no, 0–5 `score`의 선택지별 확률을 단일 순전파에서 읽는다. 비전 타워는 포함되지 않는다. 카드에 따르면 157,106행의 31B 계열 훈련 데이터를 재사용했고 원천별 라이선스는 상위 카드에 따로 있다. 카드와 GGUF 저장소에 코드·가중치·캘리브레이션 구성이 있으며 [4B GGUF](https://huggingface.co/turion-ai/turion-jev-4b-GGUF) 역시 대상일 신규(07:38 UTC). Q4_K_M 파일 2.74 GB는 **파일 크기**이고 실사용 메모리가 아니다. 다운로드·좋아요 규모를 이번 수집에서 확인하지 못해 채택도나 실전 검증으로 해석하지 않는다.

**평가의 기준:** 카드의 `Decision Index public index 0.3 suite` **51.2**는 4,214개 요청의 층화 표본 추정이고 `Proxy Full` **80.42**, 요청 중앙값 **86 ms**는 제작자 보류 세트·**NVIDIA H200** 조건이다. 독립 재현 점수가 아니다. 카드에는 자체 온도 보정 계수가 있으나 고객 업무 데이터의 ECE·Brier 및 질문/선택지 순서 바꿈 시험 결과는 없다. OpenAI·Google API와 동일 분할·동일 지표·동일 비용/지연 조건이 아니어서 직접 순위표를 만들 수 없다. 제공 코드의 `/v1/systemone` 형식은 OpenAI `/decisions`와 동일 엔드포인트라는 증거가 아니므로 변환·호환성 테스트가 필요하다. 분류·라우팅의 제한적 로컬 파일럿에는 유의미하지만 확률을 그대로 자동 승인 기준으로 쓰지 않는다.

**기존 모델 갱신:** [Turion Jev 31B](https://huggingface.co/turion-ai/turion-jev-31b/commits/main)는 10월 생성 저장소로, 대상일 커밋이 평가 순위·4B 및 GGUF 링크를 **카드에 추가**했다. 가중치 새 버전으로 부르지 않는다. [31B GGUF 저장소](https://huggingface.co/turion-ai/turion-jev-31b-GGUF)는 대상일 신규 재배포 저장소이되 원본 31B 신모델 출시는 아니다. 다른 검색 후보는 이름·카드만으로 typed decision의 재현 가능한 출력과 변경 성격이 확정되지 않아 포함 보류한다. 31B는 메모리·양자화별 실측 없이 소형 mini PC 실행 가능이라고 쓰지 않는다.
