## Hugging Face 비전 모델 및 YOLO

### 신규 비전 모델: Glance-X-Lite와 Glance-4B-v1.3b

[Glance-X-Lite 공식 카드](https://huggingface.co/Vision-Decision/Glance-X-Lite)는 영어·중국어 텍스트 요청에 따라 객체의 존재 확률과 박스를 출력한다고 설명한다. `Qwen/Qwen3.5-0.8B-Base` 기반이며 공개 저장소에는 `adapter_model.safetensors` 164MB와 `heads.safetensors` 25MB가 기술돼 있다. **기반 모델 가중치는 별도로 받는다.** `image_first`는 이미지 재사용 질의, `text_first`는 새 영상 프레임 순회에 맞춘 모드다. Glance-COCO 자체 평가 수치가 있으나 독립 벤치마크로 재검증한 값은 아니다. 라이선스 `CC BY-NC-SA 4.0`; 2026-11-20 13:07 KST 생성, [초기 가중치 커밋](https://huggingface.co/Vision-Decision/Glance-X-Lite/commit/1ad53ac0653c4184c952308f03de4153a81bb684)을 확인했다. 이미지 질의응답 전반이 아니라 **텍스트 지시 기반 객체 위치 추정**에 적합하다.

[Glance-4B-v1.3b 공식 카드](https://huggingface.co/Vision-Decision/Glance-4B-v1.3b)는 `Qwen/Qwen3.5-4B` 기반, LoRA 어댑터 122M·단일 박스 헤드 12M·다중 박스 헤드 6.6M 파라미터를 카드에 기록한다. `safetensors` 가중치와 별도 기반 모델을 결합해야 하며 라이선스는 `CC BY-NC 4.0`이다. 같은 표현에 해당하는 여러 개체를 찾아 박스와 개수 확률을 내는 목적이다. 2026-11-20 15:05 KST 생성과 [가중치 커밋](https://huggingface.co/Vision-Decision/Glance-4B-v1.3b/commit/009f449c4b0c8a2aeaa842a8f2b454f911d74d6a)을 확인했다. 카드 자체 평가의 다중 대상 F1은 특정 평가셋 기준이며 일반화된 탐지 정확도나 상용 사용 승인으로 볼 수 없다.

두 저장소의 뒤이은 카드·링크 수정은 새 가중치 공개와 분리한다. 공개 카드에서 영상·OCR 전체 태스크의 보편 성능을 입증하지 않으므로 해당 용도를 확장 주장하지 않는다. YOLO 쪽에서는 [Ultralytics 커밋](https://github.com/ultralytics/ultralytics/commit/ee5841c03)(2026-11-20 KST)의 STM32 내보내기 변경을 확인했으나 **신규 YOLO 탐지·세그멘테이션 가중치**는 이 커밋에서 확인되지 않았다.

## Decisions API와 오픈 가중치 대안

[OpenAI Decisions 공식 가이드](https://developers.openai.com/api/docs/guides/decisions)는 호스팅 API에서 `predicate`(참일 확률), `choice`(정해진 선택지), `score`(순서형 등급) 결과와 `gpt-6-luna`를 안내한다. 오픈 웨이트 제공이 아니다. [공식 변경 기록](https://developers.openai.com/api/docs/changelog)에서 대상일의 지원 입력·가격·지연시간 변경을 확정하지 못했다. Google 쪽 [공식 변경 기록](https://aistudio.google.com/docs/changelog.md.txt)에서 확인한 표기는 2026-11-11이므로 11월 20일 신규 Decisions API 공지로 재사용하지 않는다. 양사의 서로 다른 평가 점수를 직접 비교하지 않는다.

[Glance-X-Lite](https://huggingface.co/Vision-Decision/Glance-X-Lite)(11월 20일 13:07 KST, CC BY-NC-SA 4.0) 역시 이미지 입력의 **존재 판단과 위치 박스**가 중심이며 일반 문서 업무의 yes/no·choice·score 대체재로 단정하지 않는다. 같은 계열 Glance의 여러 버전·양자화 재배포는 단일 독립 계열로 본다. [miniRSI-jev-4b 카드](https://huggingface.co/k2021211255/miniRSI-jev-4b)는 26개 선택지의 멀티모달 결정 헤드와 제작자 측 Vision 평가 9,337/12,210을 기록하지만, 해당 수치를 당일 새 모델의 독립 평가로 가져오지 않았다. 카드의 재현 환경은 A800 80GB 하나를 요구한다. 이름에 `decision`이 들어간 나머지 후보를 모두 typed decision 모델로 승인하지 않았다.

**갱신 분류:** 캐시의 기존 모델 갱신 후보 중 [ken-jo/qev](https://huggingface.co/ken-jo/qev)는 런타임 SDK 수정·가중치 변화 없음, [litert-community/decider-2b-vision-LiteRT](https://huggingface.co/litert-community/decider-2b-vision-LiteRT)는 카드·매니페스트 문구 변경으로 확인됐다. 이는 신규 가중치가 아니라 **문서·런타임만 수정**한 사례다. 다운로드·좋아요·양자화 변형별 성능과 정확한 학습 데이터 범위는 비교 가능한 근거가 부족해 미확인으로 둔다.

**비교 한계:** 두 제작자 자체 평가의 데이터셋·분할·입력 형식이 같다고 입증되지 않았다. Brier/ECE 확률 보정, 선택지 순서 교란, 한국어 재현, 안전 실패율, 비전 입력의 동일 분포 평가가 없으므로 72.5%와 75.43%를 우열로 읽을 수 없다. `predicate`/`choice`/`score` 호환 응답이 구현돼도 OpenAI의 인증·스키마·요금·지연시간까지 호환된다는 뜻은 아니다. 각 모델의 mini PC VRAM·통합메모리와 GB10 실행 성공은 별도 계측이 필요하다.

## GitHub 급상승 기술
