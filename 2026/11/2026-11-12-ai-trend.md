## Decisions API 및 공개 의사결정 모델

[OpenAI 공식 가이드](https://developers.openai.com/api/docs/guides/decisions)는 호스팅 **Decisions API**가 텍스트·이미지·JSON 입력을 평가하고 `predicate`(조건 참일 확률), `choice`(제시한 선택지), `score`(순서형 수준의 확률 가중 평균)를 반환한다고 설명한다. 이는 다운로드할 수 있는 오픈 웨이트 모델이 아니고, 일반 대화형 추론 LLM이나 강화학습 궤적용 Decision Transformer도 아니다. 가이드가 주장하는 Responses API 대비 속도는 벤더 표현이며 동일 데이터·독립 지연 측정이 없다. **12일자 문서 변경 기록과 요금 변경, 지원 입력의 당일 변경은 미확인**이다. 가격이나 지연의 신구 수치를 임의로 제시하지 않는다.

참조 모델 [semgram/decider-75M](https://huggingface.co/semgram/decider-75M): Hub 메타데이터상 약 75M급 텍스트 분류, `jhu-clsp/mmBERT-small` 기반, `cc-by-4.0`, `model.safetensors`·코드·평가 결과 파일 공개, 데이터셋 표기 `LocalLLaMA/typed-decisions`. 마지막 갱신 **2026-10-31 20:25 UTC**라 오늘의 신규 소식은 아니다. 모델 카드의 결정 유형별 예측 확률 보정·독립 벤치마크, 데이터 분할, Brier/ECE, 선택지 순서 편향, 메모리 실측·양자화, 이미지 입력 및 Decisions API 프로토콜 호환성은 이번 확인 범위에서 **미확인**. mini PC와 GB10 실용성도 실측 전에는 미확인으로 둔다. 서로 다른 평가셋에서 나온 제작자 수치와 API 벤더 주장을 직접 순위화하지 않는다.

일정은 행사 주최 측 페이지 기준이며 **11월 13일 이후 12개월** 범위에서 확인했다. 등록과 논문 제출·전시 부스 신청은 별개다.

## 적용 판단과 한계

**사실과 실행의 경계:** NVIDIA는 경영진 변경을 발표했지만 공급 차질은 발표하지 않았다. Ultralytics의 수치는 특정 컴파일·엔진 조건의 제작자 측정이다. Pickle 사용기는 독립 보안 감사를 대체하지 않는다. **제안:** 현장 비전 모델을 도입할 때 입력 분포·배치·FP32/INT8 정확도·실제 mini PC/GB10 메모리 최고치 및 첫 실행 비용을 기록하고, 에이전트는 권한·승인·감사 로그부터 검증한다. 공개 범위가 확인되지 않은 모델이나 대상일 밖에 게시된 모델을 당일 출시로 설명하지 않는다.
