## Decisions API와 공개 가중치

[OpenAI Decisions 공식 문서](https://platform.openai.com/docs/guides/decisions)의 `predicate`(참일 확률), `choice`(제시한 선택지), `score`(순서형 척도)는 **호스팅 호출 형식**이며 가중치 다운로드를 의미하지 않는다. 대상일 공식 변경 로그에서 새로운 가격, 지연시간, 이미지 입력 지원 변화를 확정하지 못했다. [Google Gemini API 문서](https://ai.google.dev/gemini-api/docs/)도 별도 호스팅 제품 근거로만 취급하며, 대상일의 별도 Gemini Decisions API 발표는 확인되지 않았다. 일반 대화형 추론 LLM이나 강화학습용 Decision Transformer를 이 범주의 신규 대안으로 치지 않는다. 구조화 선택을 흉내 낼 수 있다는 것과 확률 보정된 호스팅 API의 대체 가능성은 다르다.

[GitHub 일간 Trending](https://github.com/trending?since=daily)과 [주간 Trending](https://github.com/trending?since=weekly)을 열었지만 지금 표시되는 동적 목록을 **25일 기준의 역사 스냅샷**으로 환산할 수 없다. 원본 릴리스의 대상일 변경·최근 30일 중복 여부 및 별 증가량을 함께 확인하지 못한 프로젝트를 급상승 기술로 소개하지 않는다. 이는 관련 기술이 없다는 뜻이 아니라 검증 기준 미달이다.

**분석:** 텍스트 의사결정 워크플로는 공개 2B/4B 후보의 로컬 분기 실험이 가능하더라도 확률 교정·거절 정책·감사 기록을 별도로 시험해야 한다. 실제 금융·의료·채용 결정에는 제작자 카드의 자체 평가만으로 채택하지 않는다. 비전 탐지는 동물 종·촬영 조도·카메라 구도별 현장 데이터를 분리해 재현율과 오탐을 재측정한 뒤에야 mini PC 배포를 판단한다. **미확인:** 사용자 기기별 VRAM/공유 메모리, 카드의 독립 성능, API 당일 개정, Threads 전체 타임라인, 뉴스 후보 원문. 실패한 수집을 ‘없음’으로 바꾸지 않는다.
