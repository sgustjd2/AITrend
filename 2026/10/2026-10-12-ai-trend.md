## 1. 주요 AI 이슈 (@choi.openai Threads)

Threads 접근 실패: 프로필은 열렸지만 15회 스크롤 후에도 대상일 게시물 구간까지 내려가지 못함(노출된 가장 오래된 시각이 2026-10-13 04:00:52 KST).

### 확인 방법과 범위
- [@choi.openai 프로필](https://www.threads.com/@choi.openai?hl=ko)을 실행 전 점검의 전용 Chrome에서 열어 읽기만 했다. 로그인 화면·캡차·체크포인트는 보이지 않았고 좋아요·댓글·팔로우 등 상호작용은 하지 않았다.
- `time[datetime]` 8개 고유 링크를 수집했다. 최신은 `2026-10-12T22:00:36Z`(10/13 07:00:36 KST), 가장 오래된 것은 `2026-10-12T19:00:52Z`(10/13 04:00:52 KST)였다. 15회 천천히 스크롤했으나 추가 과거 글이 로드되지 않아 대상 구간(10/11 15:00Z~10/12 14:59:59Z)에 도달하지 못했다.
- 따라서 대상일 게시물의 유무·본문·반응 수치를 확인할 수 없다. 다른 출처의 이슈를 Threads 게시물인 것처럼 대체하지 않는다.
- 경계 점검: Meta 공식 뉴스룸은 Muse Wonder 발표를 현지 날짜 10/12로 표시하지만 `article:published_time`은 `2026-10-12T17:08:05Z`로, KST 환산 시 10/13 02:08:05다. 대상일 밖이므로 본문 이슈로 수록하지 않았다.[1]

### YOLO 계열 — VLM과 분리
- [AXERA-TECH/yolo26](https://huggingface.co/AXERA-TECH/yolo26)는 2026-01-16에 생성된 기존 모델 저장소다. 10/12 17:35:35 KST 변경에서 `ax8860/yolo26s_npu4.axmodel` 파일이 추가된 것은 확인했으나, 새 YOLO 아키텍처 출시가 아니라 AXERA NPU용 모델 파일 제공이다.[6]
- 저장소 카드에 AGPL-3.0 및 AXERA 가속기/칩셋별 실행 경로가 표시된다. Mini PC 일반 CPU/GPU 또는 NVIDIA GB10 호환 증거로 볼 수 없으므로 해당 기기 적합성은 판정하지 않는다. YOLO11에도 같은 날 AXERA NPU 파일 변경이 있었으나 별도 신규 모델로 중복 상세하지 않는다.[7]

### 용도별 판정
- **OCR·문서 이해:** IlhaOCR는 카드상 CPU ONNX 경로와 낮은 메모리 수치가 있어 소형 CPU 장치 후보(게시자 벤치마크 기준). 한국어 필기라면 0.8B ko-hand-ocr-vl이 특화 후보지만, 별도 실제 구동 검증이 필요하다.
- **영상 요약·시간 grounding:** EVIDENT는 요약 생성보다는 영상 내 질의 관련 구간을 찾는 7B 기반 연구 어댑터다. GB10 추론 및 Mini PC 배포는 카드 근거 부족으로 판정 보류.
- **객체 탐지:** YOLO26 NPU 파일은 AXERA 전용 포맷이다. YOLO 기반 파일을 확인했지만 Mini PC/GB10용 범용 실행 파일이나 대상일 새 아키텍처 업데이트로 확대 해석하지 않는다.
- **GUI grounding·세그멘테이션:** 이번 표본에서 10B 이하이면서 대상일 가중치 변경, 사용 목적, 하드웨어 근거까지 함께 확인된 대표 후보를 확정하지 못했다. 이는 HF 전체에 후보가 없다는 뜻은 아니다.

- HF에서는 0.8B 한국어 필기 OCR VLM, 34.05MB INT8 CPU OCR 모델, Qwen 기반 7B 비디오 grounding 어댑터와 AXERA NPU용 YOLO26 파일 변경을 구분했다. Mini PC/GB10 적합성은 공개된 경량 CPU 벤치마크가 있는 OCR 후보 외에는 주장하지 않았고, 해당 수치도 게시자 보고로 표시했다.
- GeekNews 대상일 노출분에서는 코드 검색 CLI, MCP 서버, 검색 리랭커 관련 글을 확인했다. 추가 로드 범위 미확인으로 전체 건수는 확정하지 않았다.
- 세 기술 블로그 중 toss.tech에 대상일 글 1건, inpa와 goddaehee에는 RSS상 신규 글이 없었다.
- GitHub의 10/13 Trending은 당일 자료가 아니므로 대상일 급상승 근거에서 제외했다. 대상일 star 추이 스냅샷 부재와 GitHub API shell 호출 차단으로 단기 증가량은 확인 불가다.
- 주요 제한: Threads 과거 게시물 미노출, HF 최대 100개/태스크 표본과 일부 카드·실기 미검증, GeekNews 20개 노출 한도, GitHub의 과거 지표 부재. 검색 스니펫은 검증된 원문으로 취급하지 않았다.
