### 조사 방법과 제한

- 이 방식은 API 응답 상한이 있어 전체 목록 전수조회가 아니다. `mask-generation`·`keypoint-detection`의 별도 완전 조회 및 유력 후보 전부의 카드/커밋 대조도 마치지 못했다. 일부 공개 모델의 커밋 API가 인증을 요구해 401이 났다. 따라서 API `lastModified`만으로 신규 모델이라 단정하지 않았다.

### 경량·용도 판정
- **Mini PC:** Nau-OCR 카드의 일반 CPU 실행 설명은 있지만 메모리 요구량·파라미터 수가 없어 0.5B~8B 기준 충족을 판정할 수 없다. 실제 CPU 테스트로 오인하지 않도록 적합 판정을 보류했다.
- **GB10:** 두 후보 모두 CUDA/GB10 공식 지원이나 GB10 메모리 측정 근거를 확인하지 못했다. 구동 적합 판정 없음.
- **OCR·문서 이해:** Nau-OCR은 Dhivehi 문서에 특화된 line-cut 및 seal-removal 기능 변경이 관심 지점이다. 새로운 가중치 공개와 혼동하지 않는다.
- **객체 탐지·YOLO:** API 결과는 개인 데이터셋 파인튜닝·소규모 변환 중심으로 보여 대표 후보를 확정하지 않았다. 새 Ultralytics YOLO 모델 출시나 공식 YOLO 업데이트는 확인하지 못했다.
- **VLM·영상 요약·GUI grounding·세그멘테이션:** 해당일 대상 10B 이하 후보 중 카드 변경·크기·라이선스·런타임까지 확인해 추천할 만한 모델을 이번 표본에서는 찾지 못했다. 이는 전체 부재를 뜻하지 않는다.

## 6. 요약 및 커버리지/한계

- Threads에서는 대상일 게시물 하나와 연결 답글을 확인했다. 내용은 AI 연계 사이버 위기 대비 훈련에 대한 소개이며, 원문 보도의 주장을 독립 검증된 사실로 확대하지 않았다.
