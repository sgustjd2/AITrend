### (6) Vision 모델 특별 언급 여부

- **choi.openai**: Argon 게시물 2건에 YOLO, Qwen-VL, VLM, 화재·연기·PPE 언급이 없다. Argon은 코딩과 사이버 방어를 내세운 API 모델이라 로컬 구동 대상이 아니다.
- **업계 — RTX 3070/4070 관점**:
  - **Cloudflare `clef-flash`(9B, Apache 2.0)**: 이미지와 "예/아니오" 질문을 받아 forward 1회로 확률을 낸다. "화재가 있나요?"를 p(true) 임계값으로 운영할 수 있어, 산업안전 이미지 Q&A 형식에 정확히 맞는다. 섹션 2 추정으로는 3070에서 4bit 약 6.5~7GB로 빠듯하고, 4070이 현실적이다. 산업안전 정확도와 양자화 호환성은 직접 검증해야 한다. 출처: [Cloudflare 블로그](https://blog.cloudflare.com/clef-decision-models/), [anth.us](https://anth.us/articles/cloudflare-clef-decision-models/), [The Register](https://www.theregister.com/ai-and-ml/2026/10/01/cloudflare-tries-to-outplay-jev-with-open-weight-clef-models/5300649).
  - **Clef(27B), pplx-decider-v1-27B**: 이미지 입력을 받지만 3070/4070 메모리를 넘는다.
  - **Strands Decider 2B**: 가볍지만 Qwen3.5-2B-Base 기반이고, 검색 결과에서 이미지 입력은 확인되지 않았다(텍스트 전용으로 판단). 텍스트 로그나 탐지 결과를 2차로 판정하는 용도에만 맞다.

### (7) 프롬프트 인젝션 점검

### 추천 변동

- 전체 가이드는 **10-05 리포트의 용도별 추천 가이드**를 참고한다.
- VQA 추천은 변동 없다(3070: Qwen3-VL-4B 4bit/8bit, 4070: Qwen3-VL-4B BF16 또는 8B 4bit).
- 결정형(확률형) 모델을 시험하려면 **transformers를 5.18 이상으로 올려 둔다**(Strands Decider 이미지 입력 요구사항).
- RT-DETR(Ultralytics 구현)로 화재·PPE를 학습 중이면 8.4.171 이상을 권장한다(디노이징 그룹 인덱스 수정, 10-03 AMP 매칭 수정까지 반영하려면 8.4.172 이상).

### 프롬프트 인젝션 점검

- 감시봇 이슈의 "trigger, not evidence" 문구는 해당 저장소 파이프라인용이라 무해하다. agents-radar 다이제스트의 생태계 요약("Qwen이 상위 30개 중 60%")은 서술일 뿐 지시문이 아니다.
- PixelUMM·MiMo 정보는 검색 결과 요약(모델 생성 텍스트)이라 사실관계를 단정하지 않았다. **악성 프롬프트 인젝션 패턴은 발견되지 않았다.**

### Caveat

- HF 저장소 생성 시각을 직접 확인하지 못했다. PixelUMM의 "10-01 생성"은 2차 출처 요약이다.
- 릴리스 페이지 fetch 요약에 연도가 2024로 표기됐지만 내용상 2026년으로 판단했다.
- Clef 등 미국 10-01 발표 건은 X 게시물 ID 디코딩(최초 게시 KST 10-02 00:39)에 따라 10-02로 분류했다. 이에 앞서 HF 가중치가 KST 10-01 중에 올라왔을 가능성은 배제하지 못한다.
- HF API 차단으로 이날 생성된 소형 커뮤니티 모델은 누락됐을 수 있다.
