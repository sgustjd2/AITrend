### 확장 배포 경로의 위협: 설치 여부 확인이 먼저

**확인 사실.** [Phorion 원문](https://phorion.io/blog/offical-claude-code-vsx-compromise/)의 표기 게시일은 **2026-10-30(시간대·시각 미표시)**이고, [GeekNews 게시](https://news.hada.io/topic?id=36295)는 **2026-10-30 15:34 UTC = 31일 00:34 KST**다. 후자를 대상일 커뮤니티 소개로 분류한다. 원문은 Open VSX에 배포된 Claude Code 확장 2.1.313의 `extension.js` 선두에서 악성 코드가 확장 활성화 이전에 실행되고, SSH 인증 키·역방향 터널·운영체제별 지속성 설정을 시도했다고 분석한다. 게시자는 관련 릴리스가 회수됐다고 적는다. **분석과 영향 버전은 연구자 보고**이며 모든 설치본·이 컴퓨터가 감염됐다는 뜻은 아니다.

**적용 판단.** 사용했다면 편집기 확장 출처·설치 버전, `authorized_keys`, LaunchAgent, 연결 기록을 내부 사고대응 절차로 확인한다. 삭제만으로 충분하다고 가정하지 말고 호스트 침해 범위에 따라 토큰 교체를 결정한다. 본 브리핑은 호스트 스캔이나 파일 삭제를 수행하지 않았다. 공개 스킬·플러그인의 설치·업데이트와 모델 가중치의 신뢰 경계도 동일하게 점검한다.

### 작은 모델의 하드웨어 적합성은 정확성 검증을 대신하지 못한다

**확인 사실.** [NagaYu Core ML 저장소](https://huggingface.co/NagaYu/SmolVLM-256M-Instruct-CoreML)의 초기 생성은 **30일 16:54:26 UTC(31일 01:54 KST)**, 패키지 업로드는 **17:36:09 UTC(02:36 KST)**, 카드 수정은 **17:42:40 UTC(02:42 KST)**다. 2025년의 [원본 256.48M 모델](https://huggingface.co/HuggingFaceTB/SmolVLM-256M-Instruct)을 Apple Silicon용 Core ML로 변환했으며 이미지 설명·질의응답에 쓴다. 원본과 변환 가중치 Apache-2.0, 변환 코드 MIT, 비전 부분 FP16·언어 prefill/decode FP16 또는 INT8. 제작자 시험은 macOS 26.5에서 CPU-only와 CPU+Neural Engine 모드가 오류 없이 잘못된 캡션을 낸다고 기록한다. 이는 **제작자 장치 관측**으로 모든 버전에 대한 독립 재현이 아니다.

[WebBrain Compass VLD v6](https://huggingface.co/webbrain-one/webbrain-compass-vld-v6-2b)는 **31일 11:57:46 UTC(20:57 KST) 생성**, **12:07:06 UTC(21:07 KST)** 가중치·카드 업로드. HF BF16 safetensors의 파라미터 계수 **1,918,181,888개**, 파일 크기 **3,836,417,920바이트**(Hub 표시). 라이선스는 `other`/LFM Open License v1.0; 상업적 재배포 권한은 별도 약관 검토가 필요하다. Q4 파일만으로 영상 입력의 총 요구량을 셀 수 없다. 제작자 시각 평가와 검증 수치는 외부 독립 시험이 아니다.

[Qwen3.5-0.8B Picture-Captioner](https://huggingface.co/agentlans/Qwen3.5-0.8B-Picture-Captioner)는 **31일 05:00:58 UTC(14:00 KST)** 가중치를 올린 기존 Qwen 기반 캡션 미세조정이다. ### YOLO는 VLM과 별개이며 이번 변화는 훈련·저장 경로다

**확인 사실.** [Ultralytics 8.4.194](https://github.com/ultralytics/ultralytics/releases/tag/v8.4.194)는 30일 18:54:49 UTC(31일 03:54:49 KST) 출시됐다. 훈련 데이터 크기와 라벨을 반영한 자동 배치 크기 계산, 과거 PyTorch의 역전파 메모리 초과 처리, 비PNG 의미 분할 마스크 캐시, 예측 결과 파일명·URL 스킴 처리 등을 수정한다. 새 모델 구조·신규 탐지/분할 가중치가 아니다. [기존 YOLO26 모델](https://docs.ultralytics.com/models/yolo26/)의 박스 탐지와 인스턴스·의미 분할은 각기 다른 가중치·출력 마스크를 요구한다. 공개 사용은 AGPL-3.0/기업 라이선스 조건을 별도 검토한다. **판단:** AutoBatch 수정은 학습 과정에 유용할 수 있으나 추론 속도 향상으로 오인하지 않는다. 기존 모델을 재현 가능한 샘플에서 재학습·재검증하고 원래 마스크의 레이블 경로와 출력 저장 결과를 점검한다.

## AI/Vision 업무 적용 판단과 한계

1. **작은 이미지 모델:** Core ML 변환의 `.all`과 `.cpuAndGPU` 출력을 원본 이미지별 정답과 비교하고 OS 업데이트 때 다시 점검한다. 실행 성공과 정답을 분리한다. NPU 전용·MLX·GGUF·BF16은 서로 대체 파일이 아니다.
2. **현장 탐지:** 기존 YOLO를 훈련·분할 흐름의 회귀 테스트 대상으로 두고, VLM에는 별도 화면 질문·문서 OCR 정답지를 쓴다. 대상 mini PC의 실제 통합메모리·독립 VRAM, GB10 64/128GB 구성, 입력 해상도, 문맥·KV 캐시·동시 요청을 측정해야 채택할 수 있다.
3. **에이전트와 공급망:** 외부 스킬·확장·가중치는 버전·출처·서명·실행 권한을 감사한다. 화면의 비신뢰 문구가 도구 명령으로 이어지지 않도록 격리·승인 단계를 둔다. Orkas 이동 수정은 코드 증거일 뿐 독립 설치·동작 시험은 없다.
4. **증거 공백:** Threads 대상일 공개 permalink, Toss 전체 신작 여부, HF 허브 전체 갱신, 31일 역사적 Trending, 모델별 mini PC·GB10 피크·한국어 성능, 실제 침해 여부와 행사 실시간 재고는 확인되지 않았다. 이를 확인된 효과나 사건으로 부풀리지 않는다.
