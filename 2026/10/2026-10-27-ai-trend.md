## 주요 AI 이슈와 Threads

### LFM3-VL-2B: 발표일과 저장소 커밋 시각은 다르다

**확인 사실.** [Hugging Face 공식 발표](https://huggingface.co/blog/LiquidAI/lfm3)는 **2026-10-27 게시**. 텍스트·이미지·영상 입력으로 질의응답·문서/차트/앱 화면 읽기, 물체 위치 관계 이해를 지원한다고 밝힌다. 제작사 내부 62개 비전 평가 평균은 선행 3.1B 모델 57.6 대비 71.4이나, 독립 시험이나 한국어 현장 영상 점수는 아니다. [Hub API](https://huggingface.co/api/models/LiquidAI/LFM3-VL-2B?blobs=true)의 저장소 생성은 10월 19일 UTC, 현재 커밋은 **10월 27일 16:24 UTC = 28일 01:24 KST**. 따라서 27일 *가중치 커밋*이라고 쓰지 않고 **27일 공식 발표**로 분류한다. [공식 모델 카드](https://huggingface.co/LiquidAI/LFM3-VL-2B)는 코딩·복잡한 다중 대화를 권장하지 않는다.

**업무 해석.** 기기별 자원 시험 전에는 카메라 영상으로부터 공간 추론 정확도를 결정하거나 안전 제어에 바로 연결하지 않는다. 샘플링 2fps, 영상 프레임 수·입력 해상도에 따른 처리량과 오탐을 별도 측정한다. 카드 예제에는 `trust_remote_code=True`가 있어 다운로드 코드 감사를 먼저 해야 한다. 비전 질의응답은 탐지·분할 마스크를 직접 출력하는 YOLO의 역할과 다르다.

### Unlimited-OCR-2: 기존 가중치에서 정식 발표·벤치마크로

**확인 사실.** [Baidu 카드 릴리스 기록](https://huggingface.co/baidu/Unlimited-OCR-2)은 **2026-10-27**에 `Unlimited OCR 2`와 [MarathonDocBench](https://huggingface.co/datasets/baidu/MarathonDocBench)를 공개했다고 적는다. [당일 커밋](https://huggingface.co/baidu/Unlimited-OCR-2/commit/9cf077c4b206e0e2a31879df937b0b0bcba3661c)은 README 변경이며 [모델 API](https://huggingface.co/api/models/baidu/Unlimited-OCR-2?blobs=true)의 현재 최종 수정은 13:35:48 UTC = 22:35:48 KST. 전날 보고한 가중치 공개를 다시 당일 신규 모델이라고 부르지 않는다. 제작사가 주장한 SR-SWA의 고정 참조 집합(예: 512 토큰)과 긴 문서 처리 성능은 독립 재현 전까지 제작사 평가다.

**업무 해석.** 다쪽 계약서·기술문서에서 페이지 경계를 가로지르는 표·인용을 검증할 후보. 모델 카드의 시험 장비는 NVIDIA A800 80GB이며 SGLang 서비스는 별도 휠과 메모리 설정을 요구한다. 고객 문서로 외부 데모를 시험하지 않고 비식별 자료로 누락률·표 구조·총 처리 시간을 측정한다.

### YOLO26-seg 학습 개선과 배포 수정은 새 탐지기 출시가 아니다

**확인 사실.** [공식 릴리스 API](https://api.github.com/repos/ultralytics/ultralytics/releases/tags/v8.4.190)의 8.4.190 게시 시각은 **2026-10-26 15:51:17 UTC = 27일 00:51:17 KST**. 마스크 겹침을 고려하는 학습 양성 할당을 YOLO26-seg에 도입하고, CoreML 분할 중복 검출·MPS 출력 정밀도 오류를 수정한다. RKNN 깊이 모델의 INT8 내보내기와 FastSAM의 유효 마스크 없는 텍스트 프롬프트 처리도 고쳤다. **다른 세그멘테이션 모델과 추론/내보내기 동작 자체는 마스크 할당 변경 범위 밖**이며 새 YOLO 가중치나 대상 장비 성능 수치는 발표하지 않았다. 다음 8.4.191 릴리스는 API상 10월 27일 17:53 UTC, 즉 **28일 KST**라 제외한다.

**업무 해석.** 기존 YOLO26-seg로 재학습하는 경우 작은 물체·경계 마스크의 mAP와 오검출을 이전 버전과 같은 데이터/시드에서 비교한다. 배포 수정은 해당 CoreML/MPS/RKNN 장비에서 따로 재현하며, 모델 파라미터나 mini PC 메모리를 패키지 버전에서 유추하지 않는다.

## AI/Vision 업무 적용 판단·한계

1. **비전 실험:** LFM3-VL은 위치 관계 질문·카메라 장면 설명 후보로, YOLO26-seg는 클래스/마스크 검출 후보로 분리한다. 영상의 프레임 샘플링과 지연·오탐·한국어 질문 품질을 고정 테스트셋에서 비교한다.
2. **문서 파이프라인:** OCR-2는 페이지가 많은 비식별 문서의 표·참조 오류를 재고, 가중치 용량과 A800 예시를 mini PC/GB10 실동작 보증으로 바꾸지 않는다.
3. **개발 도구:** 외부 스킬·플러그인의 원문 지적·프롬프트·프로젝트 파일 전송 경로를 먼저 감사한다. 사용자 승인 없이 고객 정보나 내부 소스코드를 외부 모델에 넣지 않으며 플러그인은 테스트 격리에서 검증한다.
4. **근거 경계:** Threads의 발언, 세 블로그의 당일 신규 글 부재 전수, 제조사 자체 성능의 독립 재현, 기기별 피크 메모리와 역사적 별 증가량은 미확인이다.
