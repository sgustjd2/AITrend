## 1. 주요 AI 이슈

### Meta Muse Wonder — 에이전트 작업과 지속 메모리 강조
Meta는 Muse Wonder와 Muse Wonder Full을 공개했다. 공식 게시 시각은 10월 12일 17:08 UTC, 즉 10월 13일 02:08 KST다. Muse Wonder는 Meta Model API와 Muse Code에서 개발자에게 제공하고, Wonder Full은 Muse Code 구독자에게 제공한다고 밝혔다. 발표는 법률·금융·건강 업무, 코딩, 대화 간 정보를 이어가는 Active Memory, 어려운 작업에서 재시도하고 진행하는 Active Focus를 강조한다.[1]

성능과 안전성 주장은 Meta 자체 설명이다. 상세 안전 평가 보고서는 추후 공개 예정이라 독립 벤치마크나 외부 검증이 끝난 것으로 보지 않는다.

### Anthropic 연구 — IoT 기기에서 모델 추론과 복제 과정 시험
Anthropic Frontier Red Team은 소형 모델이 저가 IoT 기기에 추론 환경을 올리고 네트워크에서 복제될 가능성을 단순화된 실험으로 조사했다. 게시 시각은 10월 12일 19:30 UTC(10월 13일 04:30 KST)다. 보고서는 Gemma4-26B-A4B를 저가 Android TV 박스 15대에 분산 실행한 데모와, 방화벽으로 분리된 테스트 환경에서의 복제 실험을 설명한다.[2]

공격 단계 일부를 의도적으로 단순화했다는 점이 중요하다. 평가용 가상 노드는 인증 없는 ADB 연결을 사용했다. GLM-5.2가 단순화된 실험에서 8개 노드 전체로 복제되는 데 성공했다고 보고했지만, 이는 실제 인터넷에서 자율 확산이 발생했다는 뜻이 아니다. Anthropic도 현재는 충분한 능력과 소형 실행 가능 크기 사이에 간극이 있으며, 연말 전망은 과거 성능 추세에 근거한 추정이라고 썼다.

## 2. Hugging Face 신규/업데이트 Vision·VLM — 경량 우선 (Mini PC · GB10)

| 모델·대상일 변경 근거 (KST) | 크기·형식·라이선스 | 용도·기기 적합성 |
|---|---|---|
| [Docling TableFormerV2](https://huggingface.co/docling-project/TableFormerV2) — API 수정 시각 10/13 16:48 | 약 52M 파라미터, safetensors, Apache-2.0, 프리뷰 | 문서 표 이미지에서 셀 구조와 경계 상자를 추정한다. 카드에서 빠른 CPU 추론을 목표로 한다고 설명하지만 이 보고서에서 Mini PC·GB10 실측은 안 했다. 프리뷰라 가중치·출력·연동 방식이 바뀔 수 있다.[3] |
| [ko-hand-ocr](https://huggingface.co/localdeel/ko-hand-ocr) — 카드/가중치 저장소 변경 10/13 15:19 | 41M, 78MB 단일 모델, safetensors, Apache-2.0 | 한글·영문 혼합 손글씨 한 줄 인식용. 작성자는 같은 PC에서의 비교 측정과 10/13 재평가 결과를 공개했다. 수치는 작성자 벤치마크이며 독립 재현이 아니다. 경량 CPU 후보지만 GB10 호환성은 별도 확인이 필요하다.[4] |
| [Arm YOLO26n 320 INT8 ONNX](https://huggingface.co/Arm/yolo26n-320-int8-onnx-raspberrypi5) — 저장소 생성 10/13 23:01 | 약 3.94MB, INT8 ONNX, 카드상 AGPL-3.0 | Raspberry Pi 5 기반 Arm Edge Linux 객체 탐지용. 모델 카드 자체 측정은 36.831ms, 27.15 FPS, peak memory 91.2MB. Arm 플랫폼 자료이므로 x86 Mini PC나 GB10 성능으로 확대 해석하지 않는다.[5] |

### 판정
- 표·문서 이해에는 TableFormerV2가 작고 CPU 지향이지만 프리뷰다.
- 한글 필기에는 ko-hand-ocr가 대상일에 변경된 실용 후보로 보인다. 비교 결과는 작성자 측 측정으로 표시했다.
- YOLO26n은 특정 Arm 기기용 INT8 배포이며, 대상 기기에서 같은 성능을 낼 근거는 없다.

### GLM-Legal — 법률 업무 흐름을 겨냥한 제한 베타

Z.ai는 GLM-5.3-Flash 기반 GLM-Legal을 법률 문서 검토, 사건 자료 교차 분석, 규정 준수 작업용으로 소개했다. 공개된 설명에는 법률 자료를 활용한 추가 학습과 에이전트 실행 환경이 포함되지만, 학습 자료의 구성과 재현 조건은 충분히 공개되지 않았다. 제품 시연은 기능 예시이지 법률 결론의 정확성 검증이 아니다.[9][10]

Vals AI가 2026년 10월 12일 공개한 독립 평가 페이지에는 Harvey Legal Agent Benchmark 19.17% ± 3.25, LegalBench 86.23% ± 0.41, Legal Research Bench 41.83% ± 3.43이 기재돼 있다. 평가 과제와 성공 기준이 달라 점수를 서로 직접 비교하거나 일반 법률 질문의 정답률로 해석하면 안 된다. Harvey LAB은 모든 루브릭 항목을 통과한 비율(all-pass)을 사용한다고 설명한다.[10][11]

현재 확인 범위에서는 제한 베타 접근이 안내됐으며, 한국어 계약·한국법 적용 성능은 확인되지 않았다. 도입 판단은 비식별·합성 자료로 근거 인용 정확도, 중요 쟁점 누락, 전문가 수정량을 측정한 뒤 내려야 한다.
