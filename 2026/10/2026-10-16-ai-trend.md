### 조사 방법
Hugging Face API의 8개 지정 pipeline_tag를 `createdAt` 최신순·limit=200으로 조회하고, 각 응답을 `WORK/hf_<tag>_createdAt.json`에 보관했다. 백필 기준 2026-10-16 KST(UTC 10-15 15:00~10-16 15:00)로 필터링한 결과 태그별 상위 200건에서 후보 201건을 확인했다. 동시각 후보가 여러 태그에 중복 노출될 수 있다. API 조회는 성공했으며, 일부 검색 결과는 개인 재업로드·파인튜닝·저반응 모델로 분류해 선별했다. 상세 API로 최종 후보 카드 정보를 확인했다. `createdAt` 시각을 KST로 변환했다.

`✅*`는 공개된 ONNX 또는 WebGPU/ExecuTorch 배포 포맷이 일반 CPU/iGPU 실행 경로를 제공한다는 점에 따른 잠정 판정이며, 카드에 기기별 메모리·호환성 검증은 없다. MiniCPM-V의 경량 파라미터 및 GGUF/양자화 포맷은 16~32GB 미니PC에서의 로컬 실행에 적합하다. Jetson/GB10은 해당 포맷을 처리할 수 있으나, 이 조사에서 실기 검증은 하지 않았다.

### 용도별 정리
- **OCR·문서 이해 / 온디바이스 VLM:** MiniCPM-V-4.7-1B 계열은 1B 규모이며, 본체 카드와 Q8_0 GGUF·INT4 변형이 같은 날 등록됐다. 메모리 예산이 작은 로컬 비전 보조·문서 질의에 우선 검토할 만하다. 단, 세 파생 저장소는 원 모델 조직의 공식 릴리스로 확인되지 않아 재배포본으로 취급한다.
- **실시간 객체 검출:** D-FINE Small의 ExecuTorch/WebGPU 변형은 브라우저·온디바이스 태그를 명시해 별도 서버 의존을 줄이는 선택지다. 카드에 파라미터가 없어 경량 기준의 완전한 검증은 불가하다.
- **OCR 텍스트 검출:** PP-OCRv6 tiny ONNX 모델은 문서의 텍스트 영역 검출용 배포본이다. 모델 크기·기기별 성능이 공개 API 메타데이터에서 확인되지 않아 실제 처리량 비교는 보류한다.

### 제외한 모델
- `NVIDIA-Nemotron-3.5-Super-VL-120B-A12B-*`, `Muse-Spark-Open-816B-A42B-*` — 10B 초과로 경량 하드웨어 조건 제외.
- `MiniCPM-V-4.7-35B-A3B-GGUF`, `Qwen3.8-27B-*`, `Qwen3.6-35B-*` — 총 파라미터가 10B 초과.
- 당일 다수의 개인 YOLO 파인튜닝·GGUF 재포장 — 좋아요·다운로드가 거의 없고 독립적 기술 변화가 확인되지 않아 본문에서 제외.
- 대상일에 `visual-question-answering`에서 조회된 `karaagedaan/visual-question-answering` — 모델 카드·반응이 빈약한 개인 모델로 유의미한 경량 신규성 확인 불가.
