## 주요 AI 이슈와 Threads

### 로컬 비전 모델의 가중치와 지원 경로가 달라졌다

**사실.** [LFM3-VL-2B 모델 저장소 초기 체크포인트](https://huggingface.co/LiquidAI/LFM3-VL-2B/commit/f83d2b0a2296aaa277f394990a9b8b949ddf9691)의 표시 시각은 27일 **16:24 UTC = 28일 01:24 KST**이고 변경 파일에 `model.safetensors`, 비전 전처리 및 영상 처리 코드가 포함된다. 저장소 자체는 [Hub API](https://huggingface.co/api/models/LiquidAI/LFM3-VL-2B?blobs=true)상 19일 생성되었다. [28일 16:28 UTC 변경](https://huggingface.co/LiquidAI/LFM3-VL-2B/commit/da10385c697f8a02ca97a8593267931f06c9ae5e)은 **29일 01:28 KST**이므로 이번 일자에 넣지 않는다. 공식 카드의 이미지·영상 질문, 문서/화면 읽기, 공간 관계 설명은 제공사 명세이지 우리 현장 정확도 검증은 아니다. 카드가 안내하는 GGUF·MLX·BF16 경로는 서로 다른 런타임/정밀도다.

**해석.** 카메라 영상으로 현장 표지를 묻거나 배치 상태를 설명하는 시험 후보로 두되, 지시 실행·안전 제어에는 연결하지 않는다. 영상 2fps 샘플링과 128K 문맥 상한은 실시간 프레임 처리 보증이 아니다. 카드의 `trust_remote_code=True` 사용 전 외부 코드와 라이선스를 검토해야 한다. [Baidu OCR-2](https://huggingface.co/baidu/Unlimited-OCR-2)는 27일 이미 공개된 3.34B OCR 모델로 [28일 README 변경](https://huggingface.co/baidu/Unlimited-OCR-2/commit/5632329a32e103d5f1add270681e0f5c1233c6e4)이 빈 날짜 항목을 더한 수준이며 새 모델 출시나 새 평가 수치가 아니다.

### 탐지·분할: 기기 내보내기 수정은 새 모델이 아니다

**사실.** [8.4.191 API](https://api.github.com/repos/ultralytics/ultralytics/releases/tags/v8.4.191)의 게시 시각 **27일 17:53:08 UTC = 28일 02:53:08 KST**. [릴리스 본문](https://github.com/ultralytics/ultralytics/releases/tag/v8.4.191)은 RKNN INT8 검출·인스턴스 분할·자세·회전 상자 내보내기 지원과 호스트 CPU의 부동소수점 상자 복호화 `tail.onnx`를 명시한다. 기존 INT8 내보내기 결과는 재내보내야 할 수 있고 ONNX Runtime이 필요하다. 검증은 RKNN 시뮬레이터에서 했으며 실제 Rockchip 보드에서 정확도 확인은 없었다. 분할 학습의 양성 앵커 탐색 개선과 추적기 변경도 포함된다. [8.4.192](https://api.github.com/repos/ultralytics/ultralytics/releases/tags/v8.4.192)는 **28일 23:46 UTC = 29일 08:46 KST**라 대상일에서 제외한다.

**해석.** YOLO26은 범주와 마스크를 출력하는 탐지 계열이지 영상 문답용 VLM이 아니다. 새 체크포인트·모델 구조·mini PC 속도 개선으로 해석하지 않는다. 실제 사용 시 NPU와 CPU를 합한 전체 지연, 분할 정확도, 장치별 ONNX Runtime 호환성, AGPL-3.0 또는 상용 라이선스 적합성을 시험해야 한다.

## AI/Vision 업무 적용 판단·한계

1. **짧은 비식별 영상으로 먼저 검증:** LFM3-VL의 물체 관계 서술과 YOLO의 박스·마스크·프레임별 검출을 다른 평가 항목으로 둔다. 현장 카메라 실시간성·경계 검출 품질은 공식 카드의 일반 수치로 대신할 수 없다.
2. **배포 수정은 이중 장치 측정:** RKNN INT8 사용 시 NPU 실행과 `tail.onnx`의 CPU 실행을 합산하고 시뮬레이터와 실제 기기의 좌표/마스크가 일치하는지 확인한다. GB10에는 Rockchip 경로를 그대로 적용할 수 없다.
3. **스킬과 고객 자료 분리:** Hallmark·Expo 같은 외부 스킬의 설치 스크립트·의존성·네트워크 호출 및 라이선스를 먼저 감사한다. 이 조사에서는 원격 코드를 실행하지 않았고 고객 문서·영상도 외부 모델에 보내지 않았다.
4. **미검증 경계:** Threads 당일 전수, 블로그의 비공개 수정, GitHub 당일 역사적 Trending, 가중치 양자화 정확도와 기기별 피크 메모리, 학회 참석 가격은 미확인이다.
