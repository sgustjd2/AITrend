## Threads와 주요 AI 이슈

### OCR을 현장 기기로 옮기되 파일 크기와 실행 메모리를 혼동하지 말 것

**사실.** [LiteRT 저장소 API](https://huggingface.co/api/models/litert-community/MiniCPM-OCR-1.0?blobs=true)는 생성 **29일 11:34 UTC(20:34 KST)**, 변환 커밋 **11:40:37 UTC(20:40 KST)**, Apache-2.0 라이선스를 보인다. 원형 [OpenBMB 모델](https://huggingface.co/openbmb/MiniCPM-OCR-1.0)은 21일 이미 공개된 1.3B OCR/VLM으로 표·수식·문서 필드를 읽는다. 이번 것은 디코더 INT8과 비전 FP16인 `.litertlm` 1,997,636,640바이트 및 비전까지 INT8인 1,589,150,752바이트의 **신규 변환 저장소**다. 카드 작성자는 Galaxy S26에서 448×448 글자 구역을 CPU로 약 11초에 처리했다고 보고하고, Pixel 8a에서는 구성에 따라 2.3GB 또는 4.2GB 사용을 적었다. 이는 제작자 환경의 실측으로 mini PC·GB10 공식 요구량이 아니다. 긴 페이지는 패딩과 타일 처리가 필요하며 한글 검증은 별도로 해야 한다.

**판단.** 영수증·설비 라벨의 비식별 샘플에서 원본 대비 글자 누락·수식 공백·표 셀 병합 오류를 비교할 후보. 모델 카드가 GPU 비전 경로에서 기기별 결과 차이와 대화 다음 턴 문제를 명시하므로 한 장씩 독립 실행하고 원본 이미지와 결과를 대조해야 한다. 입력 자료에 포함된 개인정보·현장 영상은 외부 서비스로 보내지 않는다.

### 게임 화면에서 동작을 고르는 모델은 실물 제어기와 다르다

**사실.** [Game2Player-4B API](https://huggingface.co/api/models/game2player/Game2Player-4B?blobs=true) 생성 **29일 03:11:57 UTC(12:11:57 KST)**, 초기 커밋 **03:12:05 UTC**. 카드에는 Qwen3.5-4B 기반 게임 스크린샷·과거 행동을 입력받아 키/마우스 동작을 선택하며 Apache-2.0, BF16 safetensors라고 썼다. 카드는 모델 크기 4.54B, API safetensors 총계 4,539,265,536개를 보이지만 파일별 가중치 합과 기재 파라미터 수는 같은 개념이 아니다. [저장소 파일 API](https://huggingface.co/api/models/game2player/Game2Player-4B?blobs=true)에 표시된 세 safetensors 파일의 합은 약 10.35GB 수준이다. 제작자 PlayerBench·GameWorld 결과는 원문 카드의 자체 평가이며 실제 로봇·사람 주변 안전성의 독립 검증이 아니다. 원문은 출력 동작이 `computer_use` 도구 호출 형식임을 설명하지만 이 조사에서는 어떤 동작도 실행하지 않았다.

**판단.** 화면 상태에서 행동을 고르는 관찰·계획 구조를 참고할 수 있으나, 물리 기기 실행에는 권한 분리, 시뮬레이션, 사람의 승인과 정지 장치가 먼저다. 긴 추론 65,536토큰이나 7장 이미지 설정은 모델이 항상 그만큼의 메모리에 맞는다는 증거가 아니다.

### YOLO의 CUDA 배포 안정성 수정은 모델 성능 발표가 아니다

**사실.** [릴리스 API](https://api.github.com/repos/ultralytics/ultralytics/releases/tags/v8.4.192)는 **28일 23:46:20 UTC = 29일 08:46:20 KST**를 표시한다. [공식 본문](https://github.com/ultralytics/ultralytics/releases/tag/v8.4.192)은 PyTorch 2.8 이상 다중 GPU NCCL 그룹에 선택 GPU를 명시적으로 묶고, Linux CUDA에서 ONNX Runtime CUDA 의존성과 라이브러리를 로드해 cuRAND 부재로 CPU로 떨어지는 문제를 줄인다고 한다. Docker 훈련 이미지는 PyTorch 2.15로 갱신했다. 배포 환경 수정이지 새 탐지·분할 모델, 파라미터 변경, 정확도 향상 수치는 아니다. [YOLO26 저장소 이력](https://huggingface.co/Ultralytics/YOLO26/commits/main)의 마지막 표시 변경은 9월 6일이다.

**판단.** 기존 YOLO26 탐지·세그멘테이션을 Linux NVIDIA GPU에서 운영 중이라면 장치 선택, ONNX 실행 공급자와 CPU 폴백을 재검증한다. 이 수정은 Apple Metal·AX650·Rockchip RKNN의 성능 개선을 보장하지 않는다. Ultralytics 사용 시 AGPL-3.0 및 상용 조건 검토도 별도로 필요하다.

[원본](https://github.com/toyaji/anti-stuck)은 명령의 기본 300초 제한, 백그라운드 작업 장부, 서브에이전트 시간 예산을 설명한다. 저장소는 10월 7일 생성되었고 [29일 04:49 UTC 커밋](https://github.com/toyaji/anti-stuck/commit/15038265af)은 README 안내 수정이므로 **29일 신기능 발표라고 쓰지 않는다**. GitHub API 누적 스타 2개라 급상승으로 분류하지 않는다. [하네스 소개](https://news.hada.io/topic?id=36227)는 13:29 UTC = 22:29 KST에 게시되었지만 [원본 저장소 최근 커밋](https://github.com/DaeSeokSong/oh-my-ouroboros/commits/main)은 23일이라 당일 공개 기능이 아닌 새 소개다. 원본과 소개의 스킬 수 표기가 달라 숫자 확정은 유보한다.

[GeekNews 음성 인식 소개](https://news.hada.io/topic?id=36196)는 29일 00:06 UTC = 09:06 KST 게재지만 [NVIDIA 원문](https://huggingface.co/blog/nvidia/nemotron-transcribe-granary)은 **28일 게시**다. 29일 신규 음성 모델로 재기재하지 않았다. Toss Tech의 확인된 최신 AI 비용 글은 **27일**, Inpa RSS 최신 글은 2024년, Goddaehee RSS 최신 글은 **10월 8일**. 지정 블로그의 29일 본문 신규 글은 확인되지 않았으나 홈·피드 외 신규 글 부재의 증명은 아니다.

## GitHub 급상승 기술과 중복 점검

[현재 일별 Trending](https://github.com/trending?since=daily)에 `JetBrains/thinkrail`, 주별 목록에 `cloudflare/security-audit-skill` 등이 보인다. **30일 조회 화면은 29일 역사적 순위/별 증가량의 증거가 아니다.** [ThinkRail](https://github.com/JetBrains/thinkrail)은 7월 8일 생성한 Apache-2.0 에이전트 IDE이며 별 5,988개는 확인 시 API 누적치. 29일 대상 시각 범위에 [00:10 KST 터미널 환경 수정](https://github.com/JetBrains/thinkrail/commit/940d15ca5f), [18:42 KST 백그라운드 이력 유지](https://github.com/JetBrains/thinkrail/commit/25ac79211d), [23:18 KST 하위 에이전트 공급자 확장 적재](https://github.com/JetBrains/thinkrail/commit/88a79e6cd9)가 확인됐다. 마지막 수정은 전문 도구·모델 공급자 로딩의 일관성에 의미가 있지만 설치 테스트·보안 감사는 하지 않았다. 프로젝트는 이전 보고서에도 이름이 나왔으므로 **신규 저장소가 아닌 당일 변경**으로만 정리한다.

[kern](https://github.com/getkern/kern)과 [anti-stuck](https://github.com/toyaji/anti-stuck)은 공식 당일 Trending 입증이 없고 29일 GeekNews 게재로 한정한다. 최근 30일 `AITrend/2026/10/*-ai-trend.md`의 명칭 대조에서 ThinkRail 중복 소개가 발견되어 새 프로젝트 출시로 재포장하지 않았고, LiteRT 변환본은 기존 MiniCPM 원형과 구분했다. 외부 스킬·플러그인은 설치 시 훅, 접근 권한과 네트워크 요청을 먼저 감사해야 한다.

## AI/Vision 업무 적용 판단·한계

1. **OCR 시험 설계:** 원본 촬영자료를 외부에 올리지 말고 공개·비식별 이미지로 MiniCPM-OCR 변환 전후를 비교한다. 라벨·숫자·단위·표 경계와 한국어 오류를 따로 측정한다. 제조 현장 원본 재현율이나 실시간 속도는 여기서 검증하지 않았다.
2. **모델과 장치 경계:** AX650 모델은 그 전용 NPU 바이너리이고 GB10은 CUDA/ARM 통합메모리 환경이다. 같은 2B·4B 명칭만으로 호환이나 지연을 추론하지 않는다. YOLO 박스·마스크와 VLM OCR·질의응답은 다른 평가표로 본다.
3. **도구 공급망:** 공개 에이전트 IDE·플러그인의 읽기/쓰기/네트워크 권한과 설치 스크립트를 살피고, 미검증 소프트웨어를 고객 파일이나 카메라 기기에 연결하지 않는다. 어떤 외부 저장소 코드도 이번 조사에서 실행하지 않았다.
4. **증거 공백:** Threads 당일 permalink, Hub 전수, 29일 역사적 GitHub Trending, 한국어 OCR 실측, mini PC/GB10의 실행 피크, 일부 행사 참석 가격·재고는 미확인이다. 시간대가 다른 게시물이나 28일 발표를 29일 새 소식으로 전용하지 않았다.
